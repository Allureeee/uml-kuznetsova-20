# Рефлексия

## 1. Граница системы

Системой является `служба такси`, которая отвечает за *создание и обработку заказов, подбор водителей, расчет стоимости, отмену поездок и работу с рейтингами*. Внешними по отношению к системе являются **клиент**, **водитель** и внешние сервисы, например **платежный сервис**. Граница проведена вокруг функциональности службы такси.

## 2. Наиболее полезные диаграммы

Для службы такси наиболее полезными являются `диаграмма вариантов использования`, `диаграмма классов` и `диаграмма последовательности`. **Диаграмма вариантов использования** показывает цели клиента и водителя. **Диаграмма классов** позволяет описать основные сущности предметной области и связи между ними. **Диаграмма последовательности** показывает порядок взаимодействия объектов при оформлении поездки.

## 3. Раскладка PlantUML

При автоматической раскладке элементы диаграммы могут располагаться не очень понятно. Для улучшения читаемости использовалось направление left to right direction и короткие псевдонимы элементов.
