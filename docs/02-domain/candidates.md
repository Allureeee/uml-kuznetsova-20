# Кандидаты в классы

| Существительное из сценария | Решение | Почему |
|---|---|---|
| Пользователь | класс | Общий тип для пассажира и водителя, содержит общие данные учетной записи |
| Пассажир | класс | Имеет собственную учетную запись и оформляет заказы |
| Водитель | класс | Имеет собственную учетную запись, принимает заказы и выполняет поездки |
| Заказ | класс | Имеет номер, стоимость, статус и собственный жизненный цикл |
| Поездка | класс | Представляет фактическое выполнение заказа и имеет время начала и окончания |
| Автомобиль | класс | Имеет собственный номер и модель, используется водителем |
| Маршрут | класс | Определяется системой по точкам поездки и имеет расстояние и продолжительность |
| Тариф | класс | Используется для расчета стоимости поездки |
| Платёж | класс | Хранит информацию об оплате заказа и ее состоянии |
| Оценка | класс | Хранит оценку завершенной поездки, комментарий и дату |
| Статус заказа | enum | Содержит фиксированный набор состояний заказа |
| Статус платежа | enum | Содержит фиксированный набор состояний платежа |
| Точка отправления | атрибут Заказа | В данной модели не имеет собственного жизненного цикла и поведения |
| Точка назначения | атрибут Заказа | В данной модели не имеет собственного жизненного цикла и поведения |
| Стоимость | атрибут Заказа | Является характеристикой конкретного заказа и не имеет собственного жизненного цикла |
| Коэффициент спроса | атрибут Тарифа | Используется как числовой параметр динамического ценообразования |
| Имя пассажира | атрибут Пассажира | Не является самостоятельной сущностью |
| Телефон | атрибут Пользователя | Является характеристикой учетной записи |
| Рейтинг | атрибут Водителя | В данной модели хранится как текущее значение рейтинга |
