# Актёры системы

| Актёр | Пояснение | Первичный | Задача |
|---|---|---|---|
| Пассажир | Пользователь службы такси | Да | Заказать поездку, отменить поездку, оценить поездку |
| Водитель | Водитель, выполняющий заказы | Да | Получить и выполнить заказ |
| Платёжный сервис | Внешняя система обработки платежей | Нет | Обработать оплату поездки |

## Обоснование

**Пассажир** и **водитель** являются первичными актёрами, поскольку именно они непосредственно используют систему для достижения своих целей. **Платёжный сервис** является вторичным актёром, поскольку система обращается к нему для выполнения внешней операции оплаты.
