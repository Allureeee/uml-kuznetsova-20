# Сценарии вариантов использования

## ВИ-02. Заказать поездку

**Актёр:** Пассажир (первичный)

**Цель:** оформить заказ на поездку, рассчитать ее стоимость и получить назначенного водителя.

**Предусловия:** пассажир зарегистрирован и авторизован в системе.

**Постусловия (успех):** заказ создан, стоимость рассчитана, водитель найден и назначен.

**Постусловия (неуспех):** заказ не создан либо остается без назначенного водителя.

**Тип:** базовый

**Связи:**  
include ВИ-03 «Рассчитать стоимость»;  
include ВИ-04 «Подобрать водителя»;  
extend ВИ-08 «Отменить заказ».

### Основной сценарий

| № | Действие актёра | Отклик системы |
|---|---|---|
| 1 | Пассажир указывает точку отправления | 2. Система определяет и проверяет точку отправления |
| 3 | Пассажир указывает точку назначения | 4. Система определяет маршрут |
| 5 | Пассажир подтверждает заказ | 6. Система рассчитывает стоимость |
| | | 7. Система создает заказ |
| | | 8. Система начинает поиск подходящего водителя |
| | | 9. Система получает ответ от водителя |
| | | 10. Система назначает выбранного водителя заказу |
| 11 | Пассажир получает информацию о заказе | 12. Система переводит заказ в состояние «Принят» |

### Исключения

**И-1. Некорректная точка отправления (шаг 2)**

Система сообщает, что точка отправления не определена или указана некорректно, и предлагает пассажиру указать ее повторно. Сценарий продолжается с шага 1.

**И-2. Некорректная точка назначения (шаг 4)**

Система не может определить маршрут между указанными точками. Пассажир должен повторно указать точку назначения. Сценарий продолжается с шага 3.

**И-3. Изменился коэффициент стоимости заказа (шаг 6)**

Система пересчитывает стоимость поездки по актуальному коэффициенту стоимости заказа и предоставляет обновленную стоимость пассажиру до создания заказа.

**И-4. Водитель не найден (шаг 8)**

Система продолжает поиск подходящего водителя. Если водитель не найден, система сообщает пассажиру о невозможности выполнить заказ в данный момент. Заказ остается без назначенного водителя.

**И-5. Пассажир отменяет заказ (шаг 8)**

Если заказ уже создан, но поездка еще не началась, система переводит заказ в состояние «Отменен» и прекращает подбор водителя.

### Примечание

Пассажир должен быть зарегистрирован и авторизован до оформления заказа. Отмена возможна только для уже созданного активного заказа. Оценить поездку пассажир может только после завершения поездки.

## ВИ-04. Подобрать водителя

**Актёр:** Водитель (вторичный)

**Инициирует:** ВИ-02 «Заказать поездку»

**Цель:** найти подходящего свободного водителя и назначить его созданному заказу.

**Предусловия:** существует созданный активный заказ; указана точка отправления пассажира.

**Постусловия (успех):** подходящий водитель найден и назначен заказу.

**Постусловия (неуспех):** водитель не найден, заказ остается без назначения.

**Тип:** включаемый

### Основной сценарий

| № | Действие актёра | Отклик системы |
|---|---|---|
| | | 1. Система получает созданный заказ |
| | | 2. Система определяет область поиска водителя |
| | | 3. Система выбирает доступных водителей |
| | | 4. Система проверяет расположение и доступность водителей |
| | | 5. Система выбирает подходящего водителя |
| 6 | Водитель получает предложение заказа | 7. Система ожидает ответ водителя |
| 8 | Водитель принимает заказ | 9. Система назначает водителя заказу |
| | | 10. Система передает информацию о назначенном водителе пассажиру |

### Исключения

**И-1. Нет свободных водителей (шаг 3)**

Система расширяет область поиска подходящего водителя. Если водитель по-прежнему не найден, заказ остается без назначения.

**И-2. Водитель отказался от заказа (шаг 7)**

Система не назначает отказавшегося водителя и продолжает поиск другого подходящего водителя.

**И-3. Водитель стал недоступен во время подбора (шаг 4)**

Система исключает водителя из списка доступных и продолжает поиск другого кандидата.

**И-4. Подходящий водитель находится за пределами допустимой области (шаг 5)**

Система исключает водителя из списка кандидатов и продолжает поиск другого подходящего водителя.
