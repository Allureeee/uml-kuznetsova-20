## Система

Моделируемая система — служба такси. Система позволяет клиенту оформить **заказ** на поездку и **подобрать** подходящего **водителя**. При оформлении заказа рассчитывается стоимость с учетом **динамического ценообразования** . Водитель получает заказ и выполняет поездку. Клиент может **отменить** заказ в предусмотренных состояниях заказа. После завершения поездки пользователь может выставить **рейтинг**. Система также взаимодействует с внешним платежным сервисом.
