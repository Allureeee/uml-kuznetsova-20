## Система

Моделируемая система — служба такси. Система позволяет пассажиру оформить **заказ** на поездку и **подобрать** подходящего **водителя**. При оформлении заказа рассчитывается стоимость с учётом **динамического ценообразования**. Водитель получает заказ, принимает его и выполняет поездку. Пассажир может **отменить** активный заказ в предусмотренных состояниях и после завершения поездки выставить **оценку**. Система взаимодействует с внешним **платёжным сервисом** для обработки оплаты и с **сервисом карт и маршрутов** для определения координат и построения маршрута.

## Актёры и внешние системы

- **Пассажир** — заказывает поездку, отменяет заказ и оценивает поездку.
- **Водитель** — получает предложения заказов, принимает их и выполняет поездку.
- **Платёжный сервис** — внешняя система обработки оплаты поездки.
- **Сервис карт и маршрутов** — внешняя система определения координат и построения маршрута.

## ПР2 — динамика системы

В ПР2 разработаны три ракурса поведения системы:

- диаграммы последовательности и коммуникации для ВИ-02 «Заказать поездку»;
- диаграмма деятельности процесса заказа поездки;
- диаграмма конечного автомата для объекта `Заказ`.

В модели отражены ветвления, отказ водителя, отмена заказа и таймаут ожидания ответа водителя в течение 60 секунд. При таймауте подбор прекращается, а заказ переводится в состояние «Отменен».

Дополнительно созданы динамические диаграммы для ВИ-01 «Зарегистрироваться», ВИ-09 «Оценить поездку» и ВИ-10 «Оплатить поездку».

## ПР3 — архитектура и итоговый пакет

В ПР3 разработаны:

- **C4 Container** — приложения, сервисы, основная БД и очередь событий;

- единая модель в **Structurizr DSL**;
- `comparison.md` для сравнения подходов;
- `consistency-check.md` для аудита согласованности моделей;
- три ADR с архитектурными и доменными решениями;
- автоматический рендер диаграмм через GitHub Actions.

### Архитектурные решения

**ADR-0001** — заказ и поездка хранятся как отдельные сущности.  
**ADR-0002** — подбор водителя выделен в отдельный сервис.  
**ADR-0003** — для передачи внутренних событий используется очередь RabbitMQ.
